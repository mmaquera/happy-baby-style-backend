# CORS Configuration Example
# =========================

# Single frontend URL (legacy support)
FRONTEND_URL=http://localhost:3000

# Multiple frontend URLs (new flexible approach)
# Separate multiple URLs with commas
FRONTEND_URLS=http://localhost:3000,http://localhost:3007,http://localhost:8080

# Examples for different environments:
# Development: FRONTEND_URLS=http://localhost:3000,http://localhost:3007
# Staging: FRONTEND_URLS=https://staging.tudominio.com,https://dev.tudominio.com
# Production: FRONTEND_URLS=https://tudominio.com,https://www.tudominio.com

# Note: After changing these variables, restart the server for changes to take effect
